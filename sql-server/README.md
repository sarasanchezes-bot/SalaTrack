# Unidad 1 — SQL Server (base de datos relacional)

Módulo transaccional del sistema. Aquí vive la lógica que requiere integridad: salas, equipos, software, cursos, requisitos, asignaciones semestrales y mantenimientos.

## Estructura

- `schema/` — scripts de creación de la base de datos y las tablas
- `procedures/` — stored procedures
- `triggers/` — triggers de las reglas de negocio
- `seeds/` — datos de prueba para poblar las tablas
